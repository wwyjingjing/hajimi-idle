## 玩法一句话

点「喂食」生一窝 → 动物数量当钱买「生产池子」（下水道→…→时空位面 13 级）→ 池子每秒自动繁殖 → 每跨一个数量级进化 +1 级 → 冲到 **1000 亿只通关**。动物有寿命，到期同池交配、50% 遗传「基因池」外观性状；看应援视频领「加速道具」（×2 可叠到 32×）。

## 核心设计口径（防走样）

- 动物数量 = 唯一货币 = 通关进度，目标 10¹¹ 只，通关后仍可无限养。
- 数量只涨不跌：寿命是「繁殖周期计时器」，到期触发交配，不扣数量。
- 基因 = **池子级**基因池（毛色×体型×变异三字段），不是逐只动物（ADR-0001）。
- 引流闭环复用上一款：看视频领道具、每日 20 次软上限、短链降级、只说「应援/补给/加速」。
