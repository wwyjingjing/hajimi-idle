# 美术资源目录

游戏按约定文件名加载动物形态图，文件不存在时自动回退到 emoji 占位（不影响运行）。

## 命名约定

`{阵营}-{进化等级}.svg` 或 `.png`

- 阵营：`kimi`（基米队·猫）/ `dog`（大狗队·汪）
- 进化等级：`0`~`11`（奶团 → … → 千亿，共 12 级）

例如：`kimi-0.svg`、`kimi-11.png`、`dog-5.svg`

## 如何替换

1. 把真实美术导出为 200×200（建议正方形）的 PNG/SVG，按上述命名覆盖同名文件。
2. 游戏 `index.html` 里的 `animal-img` 会自动加载 `assets/{阵营}-{等级}.svg`；若你用的是 PNG，把 `ui.js` 里 `renderAnimal()` 的扩展名改成 `.png`（或直接在文件名里用 `.png` 并同步改 `ui.js`）。

## 当前内容

`gen_assets.mjs` 生成了 24 张 SVG 占位图（渐变底 + 阵营 emoji + Lv 编号），仅用于示意排版；替换后删除这些占位即可。
