# 马赛克风美术提示词（50 张动物形态图 · 25 级 × 2 阵营）

> 用法：把下面每一条直接粘贴进 AI 生图工具（Midjourney / SD / 即梦 / 豆包等）生成，导出为 **200×200 正方形 PNG**，
> 按 `assets/{阵营}-{等级}.png` 命名覆盖（`kimi`=基米队猫，`dog`=大狗队汪，等级 0~24），并把 `ui.js` 里 `renderAnimal()` 的 `.svg` 改成 `.png`。
> 每张图统一用同一段**风格后缀**，保证整套风格一致。

## 通用风格后缀（每条提示词末尾都加上）

```
像素风，马赛克风，8-bit 像素艺术，复古游戏精灵头像，方形构图，居中，纯色简洁背景，轮廓清晰，扁平色彩，高细节
```
