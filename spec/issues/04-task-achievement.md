# 04 — 任务 + 成就

**What to build:** 两套系统分开：**任务** = 主动做、领奖励（奖励 = 加速道具时长 +30 分钟），分「每日任务」（每天刷新 3-5 个）与「主线任务」（一次性，推进成长节奏）；**成就** = 达成自动点亮、纯荣誉（称号/徽章），展示在成就墙（数值里程碑 + 梗成就，含千亿通关成就）。两者均 localStorage 持久化，固定一套零维护。

**Blocked by:** 01 — 项目骨架 + 挂机核心

**Status:** ready-for-agent

- [ ] 每日任务每天刷新（喂食 N 口/拥有 X 只/买 Y 个池子/达某进化/领过一次加速等）
- [ ] 主线任务一次性（累计点击/繁殖到数量级/集齐形态等），进度持久化
- [ ] 任务完成可领取，奖励加速道具时长，余额不足不冲突
- [ ] 成就达成自动点亮（1 千/1 万/…/1000 亿里程碑 + 连点/满倍速/集齐藏品等梗成就），纯荣誉
- [ ] 成就墙独立页面展示，点亮状态持久化，可晒图
- [ ] 任务刷新/进度/奖励、成就判定在 core 层有测试（注入时钟与 rng）
