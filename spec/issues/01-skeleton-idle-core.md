# 01 — 项目骨架 + 挂机核心

**What to build:** 静态站点骨架（HTML + core/ui 模块划分 + Vitest + server.mjs/build.mjs），玩家点「喂食」生一窝，动物数量上涨；用动物数量买 13 级生产池子，池子每秒自动繁殖；累计产量每跨一个数量级种群进化 +1 级（全局效率提升、形态切换）；关页后离线收益结算（上限 8 小时）。核心为纯逻辑模块（时钟/随机数/存储注入），全程 TDD。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 手机竖屏浏览器打开页面即可游玩，无构建步骤即可本地预览
- [ ] 喂食点击动物数量即时上涨；动物数量作为唯一货币
- [ ] 13 级生产池子可重复购买，成本/秒产几何递增，池子每秒自动繁殖
- [ ] 累计产量过数量级阈值触发进化，全局效率提升、形态切换（13 级形态）
- [ ] 动物数量达 10¹¹ 通关，触发结算提示，通关后仍可继续养
- [ ] 离线收益：关页后按最后倍速×秒产结算，上限 8 小时，重开一次性领取
- [ ] 核心全部行为有 Vitest 测试（喂食/买池/秒产/进化/离线收益），时钟与随机数注入保证确定性
- [ ] 素材全部程序生成占位，无外部图片/音源
