## Problem Statement

哈基杯-基狗对邦（8.18-8.24 对邦，8.31 总结算）的胜负由「7 局对邦分 + 应援分」决定，应援分靠真人播放拉动。上一款「合成哈基米」是一个**单局 3 分钟**的快消钩子，玩家玩一局就走；赛后 7 天推流等待期（8.24-8.31）需要一个新的**高留存、低维护、纯前端**的热度引擎，让两阵营粉丝**反复回访、长时间停留**，持续为应援作品贡献真人播放，同时不碰比赛计分系统。

## Solution

一个**纯前端 H5 挂机养成小游戏**（零后端、静态托管、手机即开即玩），复用上一款已验证的引流闭环：

- 开局选阵营（基米队养哈基米🐱 / 大狗队养哈基汪🐶），阵营决定外观皮肤与文案。
- **核心循环**：点「喂食」生一窝 → 动物数量上涨 → 用动物数量买「生产池子」→ 池子每秒自动繁殖 → 指数增长 → 冲到**千亿（10¹¹）只**通关。
- **进化**：累计产量每跨一个数量级，种群进化 +1 级，全局生产效率提升，进化等级即动物形态。
- **寿命与遗传**：动物有寿命，到期触发同池交配，50% 几率遗传池子级「基因池」外观性状（毛色/体型/变异），做出"真的基因"风味。
- **引流闭环**：看应援视频 → 领「加速道具」（×2 倍速，可叠到 32×，时长累加）→ 拉长停留时间；跳转随机落在真实应援作品 + 主办方主页。
- **任务 / 成就 / 藏品**：任务给加速道具（主动回报）、成就纯荣誉（里程碑）、藏品=形态+基因图鉴（进化/交配自动收录）。
- **离线收益**：关页仍结算（上限 8 小时），重开一次性领取。

## User Stories

### 首次进入与选边

1. 打开链接无需下载无需登录即可进入游戏，选基米队/大狗队二选一。
2. 选完后看到对应阵营的动物外观、皮肤配色与文案，设置里可随时换边（存档保留）。
3. 手机竖屏浏览器正常游玩。

### 挂机核心循环

4. 点「喂食」生一窝，动物数量即时上涨。
5. 用动物数量购买生产池子（13 级：下水道→猫狗窝→房子→庄园→村庄→城市→大都会→国家→星球→星系→宇宙→克隆→时空位面），池子每秒自动繁殖，可重复购买叠加倍率。
6. 累计产量每跨一个数量级，种群进化 +1 级，全局生产效率提升，动物形态随进化等级变化。
7. 动物数量达到 10¹¹ 只通关，触发结算画面 + 专属成就 + 晒图，通关后仍可无限继续养。

### 寿命、交配与遗传

8. 动物有寿命，到期不扣数量，只触发一次同池交配。
9. 交配 50% 几率遗传成功，改动该池子「基因池」的毛色/体型/变异三字段之一，玩家可看到该池动物外观变化。
10. 离线时交配按寿命周期折算补结算（并入离线收益）。

### 引流闭环（核心 KPI）

11. 游戏内常驻「去看应援，领加速」按钮，点击开 B 站应援内容 → 2-3 秒装载动画 → 领加速道具。
12. 加速道具每层 ×2，时长累加 30 分钟，封顶 5 层（32×）；挂机产出 = 设施秒产总和 × 当前倍速。
13. 每日前 20 次点击给道具，之后只开视频不给道具并提示；跨天自动重置。
14. 跳转目标随机落在真实应援作品 + 主办方主页之间；短链失效回退原始链接，游戏不依赖短链可用。
15. 文案只提「应援/补给/加速」，不出现「刷播放/换分」。

### 任务、成就与藏品

16. 每日任务（每天刷新）与主线任务（一次性）推进成长，奖励加速道具时长。
17. 成就达成自动点亮、纯荣誉，展示在成就墙，可晒图。
18. 藏品图鉴收录形态 + 基因组合，进化/交配自动收录，集齐触发庆祝画面与专属晒图。

### 持久化与分享

19. 动物数量、生产池子、进化等级、基因池、倍速、任务、成就、藏品全部存 localStorage，重开不丢；存档损坏静默回退。
20. 双版本分享文案（阵营挑衅 / 战果炫耀）+ Canvas 晒图，一键复制/保存。

## Implementation Decisions

- **形态**：纯静态站点（HTML/CSS/JS，无构建步骤或单构建产物），零后端；复用上一款的 `server.mjs`（预览）+ `build.mjs`（生成单文件 `app.bundle.js`，file:// 可玩）+ `fetch_supports.mjs`（腾讯文档连接器）。
- **模块划分**：`core`（纯逻辑，无 DOM，时钟/随机数/存储注入）+ `ui`（渲染层），`core.test.js` Vitest 测试；`config.js` 单配置集中文案/数值/跳转目标。
- **数值模型**：
  - 动物数量 = 主数值 + 货币，通关目标 10¹¹。
  - 生产池子 13 级，成本与秒产按几何级数增长（约 ×10 成本 / 秒产递增），数值调到「3-5 天自然挂机到千亿」。
  - 进化：累计产量阈值 10¹, 10², … 10¹¹ 逐级触发，每级全局效率 ×1.2（可调）。
  - 寿命：每池子一个繁殖倒计时，到期触发交配，不扣数量。
  - 倍速：单槽位 `2^层数`，领道具层数+1 且时长+30 分钟，封顶 5 层（32×）。
- **基因池（ADR-0001）**：池子级 3 字段外观档案（毛色 8 种 × 体型 4 档 × 变异 6 种），交配 50% 成功改一字段；藏品图鉴 = 形态（13 进化）+ 基因组合（32 普通 + 6 变异），分阵营各一套。
- **离线收益**：`localStorage` 存 `lastSeen` 时间戳，重开算 `min(now-lastSeen, 8h)` 的产出（含交配折算），一次性领取。
- **引流闭环复用**：跳转目标随机（真实应援作品 + 主办方主页）、每日 20 次软上限、短链降级、合规文案口径，全部照搬上一款已验证实现。
- **持久化**：localStorage 单 key JSON；读取失败回退全新存档；每日重置按本地日期。
- **素材**：全程序生成（emoji + CSS/Canvas 几何），零外部图片音源。

## Testing Decisions

- 只测 `core` 模块（Vitest，Node 环境），只测外部行为，时钟/随机数/存储注入，测试确定性。
- **必测行为面**：
  - 喂食、购买池子、秒产累计、离线收益（注入时钟伪造离线时长与 8h 上限）。
  - 进化：数量级阈值触发、形态切换、全局效率系数。
  - 寿命/交配：倒计时触发、50% 遗传（注入 rng 命中两端）、基因池字段更新、变异封顶规则。
  - 倍速：叠层、时长累加、封顶 5 层、产出 = 秒产 × 倍速。
  - 每日任务刷新、主线任务进度、奖励发放；成就点亮判定；藏品收录与集齐。
  - 分享文案两种变体占位替换。
- **不测**：渲染、动画、跳转、localStorage 真实读写——手动验收。

## Out of Scope

- 全服排行榜/阵营实时比分（需后端，沿用上一款决策：靠选边+文案挑衅替代）。
- FEVER/评分弹幕动员（二期，8.18 对局视频发布后评估）。
- 真实立绘/音源替换（emoji 占位即最终素材，除非另行提供并确认版权）。
- 小程序/原生 App/互动视频等非静态 H5 形态。
- 应援收集表/对局表的任何读写（游戏与计分系统完全解耦）。
- 逐只动物的个体跟踪（ADR-0001，千亿规模下用池子级基因池代替）。
